# 🎬 What They Erased — MKUltra Documentary (Remotion Project)

## Что это

Полный Remotion-проект для документального ролика **"The CIA Program They Were Ordered to Destroy — Project MKUltra"** для канала **What They Erased**.

**Длительность:** ~13–15 минут
**Формат:** 1920x1080, 30fps
**Стиль:** Dark history documentary, navy blue + red glow

## Что внутри

- **Анимированное интро** — логотип канала с пульсирующим красным глазом + название эпизода
- **6 секционных титров** — анимированные переходы между секциями (I–VI) с красными линиями
- **32 сцены нарратива** — каждая с Ken Burns эффектом (zoom-in/out, pan) + субтитры
- **Fade-переходы** между всеми сценами
- **Анимированный аутро** — subscribe CTA с пульсирующей кнопкой
- **Тёмная палитра** — #0a0a14 фон, #cc0000 акценты, #f0f0f0 текст

### 3. Предпросмотр
```bash
npx remotion studio
```
Откроется в браузере на http://localhost:3000. Можно просматривать каждый кадр.

### 4. Рендер финального видео
```bash
npx remotion render MKUltraDoc output.mp4
```

### 5. Добавь озвучку

Видео сейчас **без звука**. Два варианта:

**Вариант A — Добавить в CapCut:**
Отрендери видео → импортируй в CapCut → добавь TTS-озвучку из ElevenLabs + фоновую музыку.

**Вариант B — Добавить в Remotion:**
Положи аудиофайлы в `public/audio/` и добавь компоненты `<Audio>` в `MKUltraDoc.tsx`.

## Структура проекта

```
mkultra-video/
├── public/
│   └── images/          ← СЮДА свои изображения
├── src/
│   ├── components/
│   │   ├── Intro.tsx        — Анимированное интро канала
│   │   ├── Outro.tsx        — Аутро с кнопкой Subscribe
│   │   ├── SectionTitle.tsx — Титры секций (I–VI)
│   │   ├── KenBurns.tsx     — Ken Burns эффект на изображениях
│   │   ├── Subtitle.tsx     — Субтитры нарратива
│   │   └── NarrationScene.tsx — Сцена = фон + субтитр
│   ├── data/
│   │   └── scenes.ts    — Все тексты, тайминги, пути к изображениям
│   ├── theme.ts         — Цвета, шрифты, размеры
│   ├── MKUltraDoc.tsx   — Главная композиция (собирает всё вместе)
│   └── Root.tsx         — Точка входа Remotion
└── package.json
```

## Кастомизация

### Изменить текст субтитров
Редактируй `src/data/scenes.ts` — поле `narration` каждой сцены.

### Изменить длительность сцены
Меняй `durationInSeconds` в `src/data/scenes.ts`.

### Изменить Ken Burns эффект
Меняй `kenBurns` в `src/data/scenes.ts`:
- `"zoom-in"` — медленный наезд
- `"zoom-out"` — медленный отъезд
- `"pan-left"` / `"pan-right"` — горизонтальное движение
- `"pan-up"` — вертикальное движение вверх

### Изменить цвета
Редактируй `src/theme.ts`.

### Добавить/удалить сцены
Добавь/удали объекты в массиве `SCENES` в `src/data/scenes.ts`.
